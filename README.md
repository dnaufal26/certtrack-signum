# certtrack-signum
Blockchain-based certificate verification and revocation system


## Tujuan
- Memverifikasi keaslian sertifikat PDF
- Mencatat penerbitan sertifikat
- Mencabut sertifikat melalui persetujuan dua pihak
- Menyediakan riwayat yang dapat diaudit

## Teknologi
- Solidity
- Remix IDE
- Hardhat
- JavaScript
- Git dan GitHub
